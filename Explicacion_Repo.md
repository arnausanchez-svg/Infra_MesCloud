En este repositorio se almacenará toda la documentación del proyecto de forma estructurada. Aquí se documentarán tanto los estudios de seguridad y servicios, como la configuración inicial y los documentos generales del proyecto

¿En que consiste el proyecto?
El proyecto consiste en la implementación de un sistema Nextcloud sobre un sistema operativo basado en Linux, concretamente OpenMediaVault (OMV).
